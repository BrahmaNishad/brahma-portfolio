About Me

I'm Brahma Nishad, a .NET Full Stack Developer who builds applications end-to-end — REST APIs and services in C# / ASP.NET Core, data layers in SQL Server, and front ends in React.js — across insurance, hospitality, and enterprise resource management platforms.

Comfortable owning a feature from database schema through API to UI, with working knowledge of microservices, JWT/OAuth-based auth, dependency injection, and clean design patterns — grounded in real production systems, not just documentation.
